# SportyBet Coupon Bypass

Works alongside SportyBet's frontend.

## How to Use

1. Open SportyBet.com and log in (keep it open)
2. Open this app in another tab
3. Enter your coupon/booking code
4. Click "Apply Coupon"
5. Follow the instructions to apply it on SportyBet

## Features

- Apply coupon codes to SportyBet
- Look up bet slips by booking code
- Works in parallel with SportyBet
